## Overview

This document details the database schema changes needed to transform Atlas CMMS into Atlas STR. We're **extending** the existing schema, not replacing it, so we preserve Atlas's core functionality while adding STR-specific features.

---

## Strategy

### Keep Original Tables

✓ Keep all Atlas tables intact (Asset, WorkOrder, Part, User, Location, etc.)  
✓ This allows us to merge upstream updates easily  
✓ Original Atlas features still work

### Add Extension Tables

✓ Create new tables with `_str` suffix or clear STR naming  
✓ Link to original tables via foreign keys  
✓ Add new columns to existing tables where it makes sense

### Naming Conventions

- Table names: `snake_case`
- Foreign keys: `{table}_id`
- Timestamps: `created_at`, `updated_at`
- Soft deletes: `deleted_at` (null = active)
- UUIDs for all primary keys

### 1. Property Metadata (Extends Asset)

**Purpose:** Add STR-specific fields to assets that represent properties/listings

sql

```sql
CREATE TABLE property_metadata (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  asset_id UUID NOT NULL REFERENCES asset(id) ON DELETE CASCADE,
  
  -- Listing Information
  listing_platform VARCHAR(50), -- 'airbnb', 'vrbo', 'booking', 'direct'
  listing_url TEXT,
  listing_id VARCHAR(100), -- External platform ID
  
  -- Access Details
  check_in_time TIME DEFAULT '15:00:00',
  check_out_time TIME DEFAULT '11:00:00',
  wifi_ssid VARCHAR(100),
  wifi_password VARCHAR(100),
  lockbox_code VARCHAR(20),
  access_instructions TEXT,
  parking_instructions TEXT,
  
  -- Property Details
  property_type VARCHAR(50), -- 'apartment', 'house', 'villa', 'cottage'
  bedrooms INTEGER,
  bathrooms DECIMAL(3,1), -- 2.5 for 2 full + 1 half bath
  max_guests INTEGER,
  square_meters INTEGER,
  
  -- Performance Tracking
  avg_rating DECIMAL(3,2), -- 4.87
  total_reviews INTEGER DEFAULT 0,
  total_bookings INTEGER DEFAULT 0,
  
  -- Maintenance Tracking
  last_deep_clean DATE,
  last_safety_inspection DATE,
  last_appliance_service DATE,
  next_scheduled_maintenance DATE,
  
  -- Regional Assignment
  region VARCHAR(50), -- 'Cape Town', 'Strand'
  primary_housekeeper_id UUID REFERENCES users(id),
  backup_housekeeper_id UUID REFERENCES users(id),
  handyman_id UUID REFERENCES users(id),
  
  -- Flags
  guest_favorite BOOLEAN DEFAULT FALSE,
  requires_special_attention BOOLEAN DEFAULT FALSE,
  pet_friendly BOOLEAN DEFAULT FALSE,
  
  -- Metadata
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  
  -- Constraints
  CONSTRAINT unique_asset_property UNIQUE(asset_id),
  CONSTRAINT check_rating CHECK (avg_rating >= 0 AND avg_rating <= 5)
);

-- Index for fast property lookups
CREATE INDEX idx_property_region ON property_metadata(region);
CREATE INDEX idx_property_housekeeper ON property_metadata(primary_housekeeper_id);
CREATE INDEX idx_property_listing_platform ON property_metadata(listing_platform);

-- Trigger to update updated_at
CREATE OR REPLACE FUNCTION update_modified_column()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = NOW();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER property_metadata_updated
BEFORE UPDATE ON property_metadata
FOR EACH ROW
EXECUTE FUNCTION update_modified_column();
```

### 2. Checklist Templates (AI-Generated)

**Purpose:** Store reusable maintenance checklists generated by AI or created manually

sql

```sql
CREATE TABLE checklist_template (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  
  -- Identification
  name VARCHAR(200) NOT NULL,
  description TEXT,
  appliance_type VARCHAR(100), -- 'dishwasher', 'coffee_machine', 'air_conditioner'
  brand VARCHAR(50),
  model VARCHAR(100),
  
  -- Source Tracking
  source VARCHAR(20) NOT NULL, -- 'ai_generated', 'manual', 'imported', 'community'
  manual_pdf_url TEXT, -- Link to manufacturer manual
  
  -- Checklist Steps (JSONB for flexibility)
  steps JSONB NOT NULL,
  -- Example structure:
  -- [
  --   {
  --     "order": 1,
  --     "title": "Remove spray arm",
  --     "description": "Twist counterclockwise to remove",
  --     "photo_guide_url": "https://...",
  --     "video_url": "https://...",
  --     "estimated_minutes": 5,
  --     "tools_required": ["screwdriver"],
  --     "requires_photo": true,
  --     "safety_warning": "Turn off power first"
  --   }
  -- ]
  
  -- Requirements
  photos_required INTEGER DEFAULT 0,
  min_photos_per_step INTEGER DEFAULT 0,
  estimated_duration_minutes INTEGER,
  
  -- Scheduling
  frequency_type VARCHAR(20), -- 'days', 'weeks', 'months', 'years', 'usage_based'
  frequency_value INTEGER, -- e.g., 6 for "every 6 months"
  seasonal_only BOOLEAN DEFAULT FALSE, -- e.g., AC service in summer
  
  -- Parts & Supplies
  parts_needed JSONB, -- [{"part_id": "uuid", "quantity": 1, "optional": false}]
  supplies_needed JSONB, -- [{"name": "Citric acid", "quantity": "100g"}]
  
  -- Difficulty & Skills
  difficulty_level VARCHAR(20), -- 'easy', 'medium', 'hard', 'professional'
  required_skills TEXT[], -- {'basic_plumbing', 'electrical_knowledge'}
  requires_two_people BOOLEAN DEFAULT FALSE,
  
  -- AI Metadata (if AI-generated)
  ai_confidence_score DECIMAL(3,2), -- 0.95 = 95% confidence
  ai_model VARCHAR(50), -- 'claude-3-sonnet-20240229'
  ai_generation_date TIMESTAMP,
  
  -- Usage Tracking
  times_used INTEGER DEFAULT 0,
  avg_completion_time_minutes INTEGER,
  success_rate DECIMAL(5,2), -- % of times completed without issues
  
  -- Versioning
  version INTEGER DEFAULT 1,
  previous_version_id UUID REFERENCES checklist_template(id),
  
  -- Ownership
  created_by UUID REFERENCES users(id),
  is_public BOOLEAN DEFAULT FALSE, -- Share with other users?
  company_id UUID REFERENCES company(id),
  
  -- Metadata
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  deleted_at TIMESTAMP, -- Soft delete
  
  -- Constraints
  CONSTRAINT check_frequency CHECK (frequency_value > 0),
  CONSTRAINT check_confidence CHECK (ai_confidence_score >= 0 AND ai_confidence_score <= 1)
);

-- Indexes
CREATE INDEX idx_checklist_appliance ON checklist_template(appliance_type);
CREATE INDEX idx_checklist_brand_model ON checklist_template(brand, model);
CREATE INDEX idx_checklist_company ON checklist_template(company_id);
CREATE INDEX idx_checklist_public ON checklist_template(is_public) WHERE is_public = TRUE;
CREATE INDEX idx_checklist_active ON checklist_template(deleted_at) WHERE deleted_at IS NULL;

-- Full-text search on name and description
CREATE INDEX idx_checklist_search ON checklist_template 
  USING gin(to_tsvector('english', name || ' ' || COALESCE(description, '')));
```

  -- Guest Information

  confirmation_code VARCHAR(50),
  
  -- Pricing (optional)

  currency VARCHAR(3) DEFAULT 'ZAR',
  
  -- Special Requests
  special_requests TEXT,
  has_pets BOOLEAN DEFAULT FALSE,
  early_check_in BOOLEAN DEFAULT FALSE,

  processed BOOLEAN DEFAULT FALSE,
  processed_at TIMESTAMP,
  processing_errors TEXT,
  
  -- Metadata

  updated_at TIMESTAMP DEFAULT NOW(),

  CONSTRAINT check_dates CHECK (check_out > check_in)
);

## Views for Reporting

### Active Properties View

sql

```sql
CREATE OR REPLACE VIEW v_active_properties AS
SELECT 
  a.id,
  a.name,
  a.description,
  l.name as location_name,
  pm.region,
  pm.bedrooms,
  pm.bathrooms,
  pm.max_guests,
  pm.avg_rating,
  pm.listing_platform,
  pm.listing_url,
  u1.first_name || ' ' || u1.last_name as primary_housekeeper,
  u2.first_name || ' ' || u2.last_name as handyman,
  COUNT(DISTINCT wo.id) as open_tasks,
  MAX(wo.due_date) as next_task_due
FROM asset a
LEFT JOIN location l ON a.location_id = l.id
LEFT JOIN property_metadata pm ON a.id = pm.asset_id
LEFT JOIN users u1 ON pm.primary_housekeeper_id = u1.id
LEFT JOIN users u2 ON pm.handyman_id = u2.id
LEFT JOIN work_order wo ON a.id = wo.asset_id AND wo.status NOT IN ('COMPLETE', 'CANCELLED')
WHERE a.is_property = TRUE
GROUP BY a.id, a.name, a.description, l.name, pm.region, pm.bedrooms, 
         pm.bathrooms, pm.max_guests, pm.avg_rating, pm.listing_platform, 
         pm.listing_url, u1.first_name, u1.last_name, u2.first_name, u2.last_name;
```

### Upcoming Bookings View

sql

```sql
CREATE OR REPLACE VIEW v_upcoming_bookings AS
SELECT 
  be.id,
  be.external_id,
  be.platform,
  a.name as property_name,
  pm.region,
  be.check_in,
  be.check_out,
  be.guest_name,
  be.guest_count,
  be.status,
  CASE 
    WHEN be.pre_arrival_task_id IS NOT NULL THEN wo1.status
    ELSE 'NOT_CREATED'
  END as pre_arrival_task_status,
  CASE 
    WHEN be.post_checkout_task_id IS NOT NULL THEN wo2.status
    ELSE 'NOT_CREATED'
  END as post_checkout_task_status,
  be.check_in - NOW() as time_until_checkin
FROM booking_event be
JOIN asset a ON be.property_id = a.id
LEFT JOIN property_metadata pm ON a.id = pm.asset_id
LEFT JOIN work_order wo1 ON be.pre_arrival_task_id = wo1.id
LEFT JOIN work_order wo2 ON be.post_checkout_task_id = wo2.id
WHERE be.status = 'confirmed'
  AND be.check_in >= NOW()
ORDER BY be.check_in;
```

### Task Completion Stats View

sql

```sql
CREATE OR REPLACE VIEW v_task_completion_stats AS
SELECT 
  u.id as user_id,
  u.first_name || ' ' || u.last_name as user_name,
  u.role_type,
  u.assigned_region,
  COUNT(*) as total_tasks_completed,
  AVG(EXTRACT(EPOCH FROM (wo.completed_on - wo.created_at))/3600) as avg_completion_hours,
  COUNT(*) FILTER (WHERE wo.completed_on <= wo.due_date) as compliant_tasks,
  COUNT(*) FILTER (WHERE tp.id IS NOT NULL) as tasks_with_photos,
  AVG(ARRAY_LENGTH((wo.checklist_completion_data->'steps')::json[], 1)) as avg_checklist_steps
FROM work_order wo
JOIN users u ON wo.assigned_to = u.id
LEFT JOIN task_photo tp ON wo.id = tp.work_order_id
WHERE wo.status = 'COMPLETE'
  AND wo.completed_on >= NOW() - INTERVAL '90 days'
GROUP BY u.id, u.first_name, u.last_name, u.role_type, u.assigned_region;
```
